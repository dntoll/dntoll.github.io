Who we are

Vilka vi är

Curious Engineer Studio is an indie game studio in Kalmar, Sweden. Contact: contact@curiousengineerstudio.se.

Curious Engineer Studio är en indie-spelstudio i Kalmar, Sverige. Kontakt: contact@curiousengineerstudio.se.

What this website does

Vad webbplatsen gör

This site presents the studio and our games. We do not operate user accounts, set our own cookies, or use analytics tools on these pages. Embedded third-party services may use their own storage or cookies.

Webbplatsen presenterar studion och våra spel. Vi har inga användarkonton, sätter inga egna cookies och använder inga analysverktyg på dessa sidor. Inbäddade tredjepartstjänster kan använda egen lagring eller egna cookies.

Hosting

Drift

The site is hosted on GitHub Pages. When you visit, GitHub may process technical request data such as your IP address, as described in the GitHub Privacy Statement. We do not receive visitor logs from GitHub Pages.

Sajten ligger på GitHub Pages. När du besöker den kan GitHub behandla tekniska uppgifter om anropet, till exempel din IP-adress, enligt GitHubs integritetspolicy. Vi får inte tillgång till besöksloggar från GitHub Pages.

Embedded content

Inbäddat innehåll

Some pages embed third-party content (for example a YouTube video). Those providers may process data according to their own policies when the embed loads.

Vissa sidor bäddar in innehåll från tredje part (till exempel en YouTube-video). De leverantörerna kan behandla uppgifter enligt sina egna policyer när inbäddningen laddas.

Machine Bloom ambassador applications

Intresseanmälan för Machine Bloom-ambassadörer

If you register your interest in the Machine Bloom ambassador program, we process the information you choose to provide so that we can review your application, contact you, arrange relevant test access, and administer your optional credit. This may include your contact name or nickname, email address, game interests, preferred platforms, Gmail address for Android license testing, language preference, participation interests, comments, and—only if you opt in—the exact name or nickname requested for the game credits.

Om du anmäler intresse för Machine Blooms ambassadörsprogram behandlar vi de uppgifter du själv lämnar för att kunna granska anmälan, kontakta dig, ordna relevant teståtkomst och hantera ett frivilligt namn i credits. Det kan omfatta kontaktnamn eller nickname, mejladress, spelintressen, önskade plattformar, Gmail-adress för Androids licenstestning, språkval, önskade former av deltagande, kommentarer och – endast om du väljer det – exakt namn eller nickname för spelets credits.

The application form is provided by Google Forms. Google may process form and technical request data according to its privacy policy. The information is used only for the ambassador program and is not sold. Unsuccessful or inactive expressions of interest are deleted after three months. Necessary information for active ambassadors is retained while participation continues and deleted when it ends.

Anmälningsformuläret tillhandahålls av Google Forms. Google kan behandla formulärdata och tekniska anropsuppgifter enligt sin integritetspolicy. Uppgifterna används endast för ambassadörsprogrammet och säljs inte. Ej antagna eller inaktiva intresseanmälningar raderas efter tre månader. Nödvändiga uppgifter för aktiva ambassadörer sparas medan deltagandet pågår och raderas när det avslutas.

Participation and crediting are voluntary. You can withdraw from the program, change your credit name, or ask us to remove it from future versions by emailing contact@curiousengineerstudio.se. We cannot guarantee that credits can be changed retroactively in versions that have already been published.

Deltagande och kreditering är frivilliga. Du kan lämna programmet, ändra ditt namn i credits eller be oss ta bort det från framtida versioner genom att mejla contact@curiousengineerstudio.se. Vi kan inte garantera att credits kan ändras retroaktivt i versioner som redan har publicerats.

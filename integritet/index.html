Who we are

Vilka vi är

Curious Engineer Studio is an indie game studio in Kalmar, Sweden. Contact: contact@curiousengineerstudio.se.

Curious Engineer Studio är en indie-spelstudio i Kalmar, Sverige. Kontakt: contact@curiousengineerstudio.se.

What this website does

Vad webbplatsen gör

This site presents the studio and our games. We do not operate user accounts on the website, and we do not use cookies or analytics tools on these pages.

Webbplatsen presenterar studion och våra spel. Vi har inga användarkonton på webbplatsen och använder inte cookies eller analysverktyg på dessa sidor.

Hosting

Drift

The site is hosted on GitHub Pages. When you visit, GitHub may process technical request data such as your IP address, as described in the GitHub Privacy Statement. We do not receive visitor logs from GitHub Pages.

Sajten ligger på GitHub Pages. När du besöker den kan GitHub behandla tekniska uppgifter om anropet, till exempel din IP-adress, enligt GitHubs integritetspolicy. Vi får inte tillgång till besöksloggar från GitHub Pages.

Embedded content

Inbäddat innehåll

Some pages embed third-party content (for example a YouTube video). Those providers may process data according to their own policies when the embed loads.

Vissa sidor bäddar in innehåll från tredje part (till exempel en YouTube-video). De leverantörerna kan behandla uppgifter enligt sina egna policyer när inbäddningen laddas.

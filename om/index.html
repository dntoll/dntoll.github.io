About the studio

Om studion

Curious Engineer Studio is an indie game studio based in Kalmar, Sweden. Daniel builds tactical games where systems and atmosphere matter as much as the fight.

Curious Engineer Studio är en indie-spelstudio i Kalmar, Sverige. Daniel bygger taktiska spel där system och atmosfär väger lika tungt som striden.

Our current focus is Machine Bloom: Tower Defense — a spatial tower defense game about reclaiming a machine-scarred world.

Just nu ligger fokus på Machine Bloom: Tower Defense — ett rumsligt tornförsvarsspel om att återta en maskinskadad värld.
